# Vue + Node 课程管理系统

## 项目介绍
这是一个基于 Vue3 + Node.js + Express + MySQL 的课程管理后台系统。

## 技术栈
- Vue3
- Element Plus
- Node.js
- Express
- MySQL
- JWT
- bcryptjs
- Joi

## 已完成功能
- 用户注册
- 用户登录
- JWT 登录态
- 路由守卫
- 用户信息展示
- 课程列表
- 课程分页
- 课程修改
- 课程删除
- 侧边栏折叠

## 启动方式

### 前端
npm install
npm run dev

### 后端
npm install
node app.js
